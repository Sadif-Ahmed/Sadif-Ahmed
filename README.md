# Sadif Ahmed

Lecturer in the CSE Department at BRAC University and Research Assistant at BUET. I study large language models (LLMs) in software engineering and security: secret leaks in code and issue reports, the security and privacy of LLM agents and sycophancy in vision-language models.

[Website](https://sadif-ahmed.github.io) · [Google Scholar](https://scholar.google.com/citations?user=jLFo5SoAAAAJ&hl=en) · [LinkedIn](https://linkedin.com/in/sadif-ahmed-092b60307/) · [Facebook](https://facebook.com/sadif.ahmed.562) · ahmedsadif67@gmail.com

## Projects

- **[Automated Assignment Grader](https://github.com/Sadif-Ahmed/assignment_grader_helper):** grades handwritten PDF submissions against a master solution with a two-stage multimodal LLM pipeline.
- **[WorkoutTracker](https://github.com/Sadif-Ahmed/gym-tracker):** a workout and calorie tracking web app with LLM estimates from meal photos. [Live](https://gym-tracker.sadif-ahmed.workers.dev)
- **[AuthentiDocs](https://github.com/AuthentiDocs/authentidocs):** a team collaboration platform where every file and workflow step is signed with ECDSA.
- **[Anidex](https://github.com/KyojinsAnidex/Anidex):** an online anime database with watchlists, ratings and discussion forums.
- **[Network Flow Classification](https://github.com/Mohaimin41/ml_project):** BERT and GPT-2 models for classifying network intrusion flows.
- **Course labs from BUET:** [machine learning](https://github.com/Sadif-Ahmed/CSE-472), [computer security](https://github.com/Sadif-Ahmed/CSE-406), [computer networks](https://github.com/Sadif-Ahmed/CSE-322) and [operating systems](https://github.com/Sadif-Ahmed/CSE-314).
